# uyun-bug 插件

**优云版结构化 Bug 修复工作流**

参考 Anthropic 官方插件设计模式，专为 Claude Code 设计的一套**文档驱动、闭环式** Bug 修复流程。

### 核心理念
将模糊的 Bug 现象转化为**标准化分析报告 + 可执行修复方案 + 可验证的修复结果**，通过 5 个明确阶段实现高质量、可追溯的 Bug 修复。

### 核心流程
1. Bug 分析：定位根因、复现步骤、影响范围
2. 修复方案规划：制定精准、低风险的修复方案
3. 代码修复：增量修改代码，确保精准解决问题
4. 修复验证：确认 Bug 已解决，无新问题引入
5. 回归测试：编写测试用例，防止 Bug 复现
